- id (PK, autoincrement)
- origin (3-letter IATA, uppercase)
- destination (3-letter IATA, uppercase)
- depart_date (ISO date)
- return_date (ISO date, nullable — null means one-way)
- max_stops (int, default 1)
- passengers (int, default 1)

- absolute_threshold_cad (real, nullable — alert if price drops below this)
- active (bool, default true)
- created_at (timestamp)
